# 公众号排版模板 · 藏蓝 + 红 · 章节分隔

一套可直接粘进微信公众号编辑器的排版模板：**白底正文 + 藏蓝加粗层级 + 红色章节分隔条**，配 壹/贰/叁 三张章头分隔条和一张 THE END 收尾条。

所有数值不是估的，是从一篇已发文章的发布页 HTML 里**逐条读内联样式实测**出来的（读法见 [layout-spec.md](layout-spec.md)）。

---

## 规格速查

| 项目 | 值 |
|---|---|
| 容器 | `max-width:677px` 居中，背景 **#FFFFFF** |
| 字体族 | `"PingFang SC NEW", system-ui, -apple-system, BlinkMacSystemFont, "Helvetica Neue", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif` |
| 正文 | **15px** / 行高 **1.75em** / 字间距 **0.544px** / 颜色 **#595959** |
| 段边距 | `margin: 0 16px`（文字与图片同一边距） |
| 段间距 | 靠一个空段 `<br>` 撑开约 26px，不是 `margin-bottom` |
| 层级行 | 藏蓝 **#1F4E6E** + 加粗，**字号不变，仍是 15px** |
| 强调 | 橙红 **#FF4C00** + 加粗，只用于人名/关键词首现 |
| 居中 | 仅三类：署名、END 后两句收尾语、图片；其余正文一律左对齐 |
| 分隔条 | 2160×540（4:1），文内以 100% 宽显示 |
| 头图 | 1800×766（2.35:1），放正文最上方、署名之前 |

## 文件说明

```
index.html            自包含可复制版 —— 4 张分隔条已 base64 内嵌，浏览器打开 → 全选复制 → 粘进公众号
index.relative.html   可读版 —— 图片走 assets/ 相对路径，方便看源码和改结构
layout-spec.md        排版规范：实测数值、层级规则、图文序列、不要继承的坑
build.py              生成脚本：python3 build.py 重新生成上面两个 HTML
assets/               4 张分隔条 PNG 原图（主图，2160×540）
```

`index.html` 与 `index.relative.html` 都由 `build.py` 生成，**改结构请改 `build.py`，不要直接改 HTML**。

---

## 用法

1. 用浏览器打开 `index.html`
2. `Ctrl/Cmd + A` 全选 → `Ctrl/Cmd + C` 复制
3. 粘进公众号编辑器（图片会一起带过去，因为已经 base64 内嵌）
4. 把正文里 `【】` 包住的占位说明逐段替换成你的内容

> **为什么图片要内嵌**：公众号编辑器粘不了 `file://` 或相对路径的图片，图片会直接丢。base64 data URI 才能跟着复制走。

## 替换清单

| 位置 | 要做什么 |
|---|---|
| 署名 | 「作者 \| 小铭」——改成你想要的署名 |
| 头图 | 模板里用 HTML 注释标了位置，**需要你自己插一张 2.35:1（1800×766）的图** |
| 人物图/配图 | 同样用注释标出，需要自己插，建议带 16px 边距 |
| 三张分隔条 | 已内嵌，**不要动**；若要改章数，从 `assets/` 取原图另配 |
| 正文 `【】` | 逐段替换。`【】` 里写的是这一段的功能和字数建议 |
| 结尾两句 | 「原创不易，感谢有你！」「一起转发出去，让更多人看到。」**建议整组删掉** —— 转发引导 footer 是 AI 检测的高风险触发器，详见 `layout-spec.md` 第六节 |

## 三条硬约束

1. **正文背景必须纯白。** 4 张分隔条是无透明通道的白底 PNG，换成 `#F5F5F7` 之类的底色，分隔条会露出一个白方块。
2. **层级只用一种颜色。** 全篇靠 `#1F4E6E` 加粗（字号不变）做层级，不要自己加字号差、色块或边框，一加就破。
3. **正文末尾不加签名行。** 结尾就停在两句收尾语上，不附「我是小铭，专注…」这类签名。

---

## 章节切法

模板里是 **3 章**。经验值：**每 800 字左右切一次**，按叙事段落切，**不是每个小标题都给分隔条**。分隔条给太密，文章看起来会像目录。

- 壹 → 人物与经历（含反常识转折）
- 贰 → 方法（这件事是怎么做成的）
- 叁 → 给读者的可操作动作
